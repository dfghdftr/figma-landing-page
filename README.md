# WebStudio Landing Page

## Опис проєкту

WebStudio Landing Page — це односторінковий вебсайт, створений за макетом Figma в рамках навчального персонального проєкту.

Сайт представляє компанію, що надає цифрові послуги, та містить:

* навігаційне меню;
* головний інформаційний блок;
* галерею зображень;
* блок переваг компанії;
* footer з контактною інформацією.
